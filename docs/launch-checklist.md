# Master Launch Checklist: The Business OS Elite v6.3

## 🛠️ Step 1: Technical Foundation
- [ ] Install WordPress 6.0+
- [ ] Activate **GrowthPress Theme** (Cinematic Glassmorphism v6.3)
- [ ] Activate **GrowthPress Core Plugin**
- [ ] Set Permalinks to "Post Name"

## 🤖 Step 2: AI & API Integration
- [ ] Input **Omni-AI Keys** (OpenAI, Claude, Gemini, or Ollama)
- [ ] Input **Twilio SID & Token** (Optional for SMS Triage)
- [ ] Input **Google Maps & Stripe Keys** (For regional routing & financial ledger)
- [ ] Set **Bearer API Token** (Settings > Integrations)

## 🚀 Step 3: Industry Initialization
- [ ] Run **OS Launch Wizard** from Strategic Command
- [ ] Select Niche (e.g. Solar, Law, Medical)
- [ ] Verify core pages created (Home, Services, Contact, FAQ, Portal)
- [ ] **System Tools**: Generate Sample Data to populate the 14-node ecosystem.

## 🎨 Step 4: Brand Calibration
- [ ] Set **Primary Brand Color & Radius** (Customizer > Global Branding)
- [ ] Upload **Logo** & **Social Share Image**
- [ ] Update **Hero Headline** (Customizer > Homepage)

## 📊 Step 5: Sales & ROI Operations
- [ ] Add specialist team members as Users (Assigned to `gp_staff`)
- [ ] Set **Hot Lead Threshold** (Settings > Integrations)
- [ ] Verify **Kanban Stages** and **Ecosystem Radar** metrics
- [ ] Submit test lead & verify AI probability scoring
