# GrowthPress White-Label & Agency Rebranding Guide

GrowthPress is designed for agencies to deploy as their own proprietary "Business Operating System." Follow these steps to fully white-label the ecosystem.

## 1. Global Identity (Admin & AI)
Navigate to `GrowthPress > Settings` to set your agency's presence:
- **Business/Brand Name**: This updates the main Dashboard title and how the AI Assistant refers to itself. Instead of "GrowthPress Assistant," it will say "[Your Agency] Advisor."
- **Dashboard Logo URL**: Upload your agency logo to the media library and paste the URL here. It will replace the default header in the Executive Dashboard.
- **Primary Color**: Set your brand's HEX code. This color propagates to the Chat Bubble, Kanban board highlights, and all primary action buttons.

## 2. Client-Facing Branding (Theme)
Navigate to `Appearance > Customize`:
- **Site Identity**: Upload your client's business logo and set the Site Title.
- **Global Branding**: Ensure the Primary Brand Color matches the client's brand guidelines.

## 3. Removing "GrowthPress" Footprints
- **Footer**: The theme footer is dynamic. Update the copyright text and "Powered by" line in `footer.php` or via the Customizer if a child theme is used.
- **Support Links**: Ensure any links in the "How to Use" documentation tab point to your agency's support portal instead of the GrowthPress default.

## 4. License Management
Use the **License Activation** field to manage client deployments. For high-ticket agency setups, we recommend including this OS as a "System Setup Fee" ($2,500+) plus an ongoing "Intelligence Maintenance" retainer.
