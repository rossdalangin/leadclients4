# Client Onboarding & Handover Checklist

## 🤝 Strategic Usage & Delivery
> **Persona:** Customer Success Manager or Project Lead.
> **Environment:** Kickoff Meeting or Final System Handover.
> **Objective:** Transition the client from "Implementation" to "Realization". Use this list to demonstrate that the OS is not just "live," but "calibrated for dominance."

Congratulations on deploying your GrowthPress Business OS. Use this checklist to ensure your team is ready for growth.

## 0. The "Realization" Milestone
- [ ] Confirm "CORE ACTIVE" status ping on Dashboard.
- [ ] Verify 14 relational nodes are correctly instantiated.

## 1. Intelligence Calibration
- [ ] OpenAI API Key is active (Check status on Dashboard).
- [ ] Hot Lead Threshold set (Standard: 80).
- [ ] AI FAQ Assistant trained with niche-specific data.

## 2. Brand Identity
- [ ] Primary Color set in Customizer.
- [ ] High-Resolution Logo uploaded.
- [ ] Home and Services headlines reviewed for strategic accuracy.

## 3. Operations Setup
- [ ] Staff members added as WordPress Users.
- [ ] Multi-Staff Booking calendar configured.
- [ ] (If Solar/Contractor) Pricing logic in calculators verified against current rates.

## 4. Sales Team Training
- [ ] Reps trained on Kanban drag-and-drop workflow.
- [ ] Reps trained on using the AI Lead Insights (Discovery Questions).
- [ ] Client Portal proposal acceptance workflow demonstrated to the team.

## 5. Security & Legal
- [ ] Privacy Policy and Terms pages created.
- [ ] (If Medical/Legal) Secure Document Hub tested.
- [ ] REST API Bearer Token secured for external webhooks.
