# GrowthPress Industry Module Summary

Each business niche in GrowthPress includes tailored logic, Custom Post Types (CPTs), and high-ticket sales tools.

| Niche | Key Features | Unique Tool |
| :--- | :--- | :--- |
| **Dental** | Smile Gallery, Patient Education | `[gp_insurance_optimizer]` |
| **Law Firm** | Secure Intake, Case Lifecycle Tracking | `[gp_legal_intake]` |
| **Solar** | ROI Projections, Financing Inquiry | `[gp_solar_calculator]` |
| **Contractor** | Portfolio, Project Tracking | `[gp_contractor_estimator]` |
| **Roofing** | Storm Damage Triage, Material Quality | `[gp_roofing_estimator]` |
| **Accounting** | Tax Strategy, Secure Document Portal | `[gp_tax_estimator]` |
| **Medical** | Symptom Checker, Telemedicine | `[gp_symptom_checker]` |
| **Real Estate** | Property Matchmaker, Virtual Tours | AI Listing Suggester |
| **Coaches** | Webinar Registration, Discovery Calls | `[gp_coaching_assistant]` |
| **Consultants** | Strategic Proposals, Authority Library | AI Strategy Roadmap |

## Automated Initialization
When you select a niche in the **Launch Wizard**, the system instantly generates:
1. Core pages with industry-specific copy.
2. The appropriate calculators and intake forms.
3. Sample CRM data (Leads/Projects) to demonstrate the workflow.
