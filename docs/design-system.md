# GrowthPress Design System

## Aesthetic: Premium Enterprise SaaS
The design system for GrowthPress is built on modern SaaS principles: glassmorphism, subtle gradients, and high-contrast typography.

### Color Palette
- **Primary**: #2563EB (Growth Blue) - Represents trust and growth.
- **Secondary**: #1E293B (Deep Slate) - Professional enterprise feel.
- **Accent**: #10B981 (Success Green) - Used for primary CTAs.
- **Surface**: rgba(255, 255, 255, 0.05) with backdrop-filter: blur(10px) (Glassmorphism).

### Typography
- **Primary Font**: Inter (Sans-serif) - Clean, readable, modern.
- **Heading Hierarchy**: Bold, generous spacing, high readability.

### Components
- **Glass Cards**: Semi-transparent backgrounds for dashboards and lead forms.
- **Sticky Booking Buttons**: Floats on mobile for high conversion.
- **Modern Input Fields**: Minimalist design with smooth transition effects.
- **Animated Progress Bars**: For lead qualification quizzes.
